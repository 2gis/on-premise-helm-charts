The chart applies the hardened security defaults: the containers are run as the user 10001
with a read-only root filesystem, no privilege escalation and all the capabilities dropped.
If the images require another user or a writable path, override the settings:

  securityContext.runAsUser, podSecurityContext.runAsUser, podSecurityContext.fsGroup
  writablePaths, ex: --set writablePaths={/tmp,/var/cache}

The same parameters are available per service, ex: api.securityContext, migrate.writablePaths.
